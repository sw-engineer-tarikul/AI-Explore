Type coercion

Instant type coercion at the edge.

Data Engine is the module that owns bases, tables, fields, records, formulas and relationships. Raw input is coerced to its field type the moment it arrives, so invalid values fail early and records stay clean.

Get started

Features

Typed fields

Text, number, boolean and date fields share one coercion path. Raw input is trimmed and converted at the module edge, so invalid values fail early instead of leaking into records.

Validation at the edge

FieldValues.Coerce returns a typed value or throws FormatException. Empty input becomes null, not a default.

Tested in the open

The module ships with a real xUnit suite and a CI-friendly build, so behavior is proven, not assumed.

Quick start

Call FieldValues.Coerce with a field type and the raw string. Whitespace-only input becomes null; anything the type cannot parse throws FormatException. 

using DataEngine;

var age = FieldValues.Coerce(FieldType.Number, " 42 ");   // 42m
var active = FieldValues.Coerce(FieldType.Boolean, "yes"); // true
var due = FieldValues.Coerce(FieldType.Date, "2026-01-31"); // 2026-01-31
var empty = FieldValues.Coerce(FieldType.Text, "  ");      // null

FieldValues.Coerce(FieldType.Number, "abc"); // throws FormatException
