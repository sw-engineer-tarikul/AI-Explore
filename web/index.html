Data, modeled with intent.

Data Engine is the AI-Explore module that owns bases, tables, fields, records, formulas and relationships. Every value is given a defined type and checked at the module edge, so the rest of the system can trust what it stores.

View the quick start

Small surface, strict guarantees

Typed fields

Text, number, boolean and date are first-class field types. Coercion happens at the module edge, so invalid input fails early instead of spreading through the system.

Validation at the edge

FieldValues.Coerce returns a typed value or throws FormatException. Empty input becomes null, never a silent default.

Tested in the open

The module ships with a real xUnit suite and a CI-friendly build. Its behavior is proven on every change, not assumed.

Quick start

The public surface is deliberately small: pass raw input and a field type, then handle the empty case. Here is the API in use. 

using DataEngine;

var age = FieldValues.Coerce(FieldType.Number, " 42 ");    // 42m
var active = FieldValues.Coerce(FieldType.Boolean, "yes"); // true
var due = FieldValues.Coerce(FieldType.Date, "2026-01-31"); // 2026-01-31
var empty = FieldValues.Coerce(FieldType.Text, "  ");       // null

FieldValues.Coerce(FieldType.Number, "not-a-number");       // throws FormatException
