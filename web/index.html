Data Engine

Data Engine is the module that owns bases, tables, fields, records, formulas and relationships. It keeps schema and values honest at the boundary, so everything downstream can trust the data it receives.

Start with the quick start

Features

Typed fields

Text, number, boolean and date fields share one coercion path, so every value takes the right shape as it enters the module. Invalid input fails at the edge instead of spreading through your schema.

Validation at the edge

FieldValues.Coerce returns a typed value or throws FormatException, and empty input becomes null rather than a silent default. You always know whether a value is present and valid.

Tested in the open

The module ships with a real xUnit suite covering coercion rules, empty input and failure cases. The build is CI-friendly, so documented behavior is proven on every run rather than assumed.

Quick start

Reference the DataEngine namespace and call FieldValues.Coerce with the field type and raw input. Numbers, booleans and dates are trimmed before parsing, while text keeps its original whitespace. 

using DataEngine;

var age = FieldValues.Coerce(FieldType.Number, " 42 ");   // 42m
var active = FieldValues.Coerce(FieldType.Boolean, "yes"); // true
var due = FieldValues.Coerce(FieldType.Date, "2026-01-31"); // 2026-01-31
var empty = FieldValues.Coerce(FieldType.Text, "  ");      // null
FieldValues.Coerce(FieldType.Number, "not-a-number");     // throws FormatException
