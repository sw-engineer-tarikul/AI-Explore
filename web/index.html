Instant type coercion

Raw input becomes real data, immediately.

Data Engine is the module that owns bases, tables, fields, records, formulas and relationships. It coerces every value as it enters the module, so a number is a number, a date is a date, and bad input stops right where it started.

Built for predictable data

Typed fields

Text, number, boolean and date fields each have one clear shape. Coercion happens at the module edge, so invalid input fails early instead of leaking into your records.

Validation at the edge

FieldValues.Coerce returns a typed value or throws FormatException. Empty input becomes null, never a silent default.

Tested in the open

The module ships with a real xUnit suite and a CI-friendly build, so its behavior is proven rather than assumed.

Quick start

Call FieldValues.Coerce with the field type and the raw input. Values are trimmed at the edge, and the result is either a typed value or a FormatException. 

using DataEngine;

var age = FieldValues.Coerce(FieldType.Number, " 42 ");    // 42m
var active = FieldValues.Coerce(FieldType.Boolean, "yes"); // true
var due = FieldValues.Coerce(FieldType.Date, "2026-01-31"); // 2026-01-31
var empty = FieldValues.Coerce(FieldType.Text, "  ");      // null

FieldValues.Coerce(FieldType.Number, "forty-two");          // throws FormatException
