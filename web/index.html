Data Engine

Data Engine is the module that owns bases, tables, fields, records, formulas and relationships. Every value gets a known shape at the edge, so the rest of the system can trust what it holds.

Start with the quick start

What you get

Typed fields

Text, number, boolean and date are first-class field types. Values are coerced at the module edge, so invalid input fails early instead of spreading through the schema.

Validation at the edge

FieldValues.Coerce returns a typed value or throws FormatException. Empty input becomes null, never a silent default.

Tested in the open

The module ships with a real xUnit suite and a CI-friendly build, so behavior is proven, not assumed.

Quick start

Coerce a raw string into the value shape of a field type. Numbers become decimal, booleans become bool, dates become DateOnly, and text is preserved as-is. 

using DataEngine;

var age = FieldValues.Coerce(FieldType.Number, " 42 ");   // 42m
var active = FieldValues.Coerce(FieldType.Boolean, "yes"); // true
var due = FieldValues.Coerce(FieldType.Date, "2026-01-31"); // 2026-01-31
var empty = FieldValues.Coerce(FieldType.Text, "  ");      // null

FieldValues.Coerce(FieldType.Number, "abc"); // throws FormatException
