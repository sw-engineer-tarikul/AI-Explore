Structure your data, at the edge.

Data Engine is the module that owns bases, tables, fields, records, formulas and relationships. It coerces raw input into typed values at the module edge, so invalid data fails early instead of leaking into your app.

Jump to quick start

Features

One coercion path for every field type, with validation where data enters the module.

Typed fields

Text, number, boolean and date fields share a single coercion path. Values are converted at the module edge, so invalid input fails early instead of spreading through your data.

Validation at the edge

FieldValues.Coerce returns a typed value or throws FormatException. Empty input becomes null, never a silent default.

Tested in the open

The module ships with a real xUnit suite and a CI-friendly build, so behaviour is proven by tests you can run yourself — not assumed.

Roadmap

What the module supports today, and what comes next.

  1. Field coercion

    Available now

    Text, number, boolean and date values coerce at the edge. Whitespace becomes an empty value, and input that cannot be parsed throws FormatException.

  2. Records and tables

    Next

    Records will validate their field values against the table schema before they are stored, using the same typed coercion that already guards the module edge.

  3. Formulas

    Planned

    Computed fields will evaluate against record values while staying inside the module boundary, so formula results keep the field's declared type.

  4. Relationships

    Planned

    Links between tables will resolve through typed fields, so a relationship can never point at the wrong value shape.

Quick start

Reference the DataEngine project and call FieldValues.Coerce with a field type and the raw input. It returns the typed value, null for empty input, or throws FormatException when the input is not valid for the type. 

using DataEngine;

var age = FieldValues.Coerce(FieldType.Number, " 42 ");   // 42m
var active = FieldValues.Coerce(FieldType.Boolean, "yes"); // true
var due = FieldValues.Coerce(FieldType.Date, "2026-01-31"); // 2026-01-31
var empty = FieldValues.Coerce(FieldType.Text, "  ");      // null

FieldValues.Coerce(FieldType.Number, "forty-two");        // throws FormatException
