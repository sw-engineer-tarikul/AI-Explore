Structured data, typed at the edge.

Data Engine is the module that owns bases, tables, fields, records, formulas and relationships. Every value crosses a single coercion boundary, so the rest of the system can trust what it stores.

Read the quick start

Features

Typed fields

Text, number, boolean and date fields share one small contract, with coercion at the module edge so invalid input fails early.

Validation at the edge

FieldValues.Coerce returns a typed value or throws FormatException. Empty input becomes null, not a default.

Tested in the open

The module ships with a real xUnit suite and a CI-friendly build, so behavior is proven rather than assumed.

Quick start

The public surface is a single static method. Reference the project, then coerce raw strings as they arrive from a form, an import or an API call. 

using DataEngine;

var age = FieldValues.Coerce(FieldType.Number, " 42 ");   // 42m
var active = FieldValues.Coerce(FieldType.Boolean, "yes"); // true
var due = FieldValues.Coerce(FieldType.Date, "2026-01-31"); // 2026-01-31
var empty = FieldValues.Coerce(FieldType.Text, "  ");      // null

var bad = FieldValues.Coerce(FieldType.Number, "forty-two"); // throws FormatException

Values are trimmed for validation, text keeps its original whitespace, and anything that cannot be coerced throws rather than guessing.
